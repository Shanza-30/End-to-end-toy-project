# 🎓 Student Placement Prediction using Machine Learning

## 📌 Project Overview
This project focuses on predicting student placement outcomes using Machine Learning classification techniques.  
It analyzes academic and personal factors such as IQ, CGPA, Gender, and Status, and applies Logistic Regression to classify whether a student is likely to get placed or not.

The project demonstrates a complete end-to-end machine learning workflow including data preprocessing, visualization, model training, and evaluation.


## 🎯 Objective
- Predict student placement status (Placed / Not Placed)
- Identify key factors influencing placement decisions
- Build and evaluate a reliable binary classification model


## ⚙️ Features & Functionalities
- Data cleaning and preprocessing to improve model accuracy
- Exploratory Data Analysis (EDA) using graphs and heatmaps
- Training a Logistic Regression classification model
- Model evaluation using accuracy score and confusion matrix


## 📊 Data Visualization
- Feature relationship graphs for better insights
- Correlation heatmaps to understand feature impact on placement outcomes


## 🧠 Model Training
- Uses Logistic Regression for binary classification
- Trains the model on processed data for accurate predictions


## 📈 Model Evaluation
- Accuracy score to measure overall model performance
- Confusion matrix to analyze correct and incorrect predictions

1. Download the dataset

   - NumPy  
   - Pandas  
   - Matplotlib  
   - Seaborn  
   - scikit-learn

1. Load and preprocess the dataset
2. Perform Exploratory Data Analysis (EDA)

4. Test the model and evaluate accuracy
5. Analyze results using visualizations and evaluation metrics


## 📂 Example Outputs
